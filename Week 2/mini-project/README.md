## Ringkasan halaman

Halaman ini merupakan landing page interaktif untuk Ay-Nyang!, usaha makanan ayam. Halaman terdiri dari header, navigasi, hero, benefit, menu, informasi, FAQ, kontak, dan footer. Halaman menggunakan HTML semantik, CSS murni, dan JavaScript tanpa framework. Layout dibuat responsif untuk berbagai ukuran layar.

## Perbedaan dari Modul 1

Pada Module 1, halaman Ay-Nyang! masih berupa landing page statis yang berfokus pada struktur HTML dan tampilan CSS. Navigasi hanya berupa link, daftar menu ditulis langsung pada HTML, dan form kontak belum memiliki validasi.

Pada Mini Project ini, halaman dikembangkan menjadi lebih interaktif menggunakan JavaScript. Beberapa perubahan yang ditambahkan adalah:

1. Navigasi mobile dapat dibuka dan ditutup menggunakan tombol Navigasi.
2. Daftar menu disimpan dalam array of objects dan ditampilkan secara dinamis menggunakan JavaScript.
3. Ditambahkan filter kategori untuk menampilkan menu berdasarkan pilihan pengguna.
4. Ditambahkan FAQ accordion sehingga pengguna dapat membuka dan menutup jawaban pertanyaan.
5. Form kontak memiliki validasi nama, email, dan pesan serta menampilkan pesan berhasil ketika data valid.
6. Ditambahkan tombol kembali ke atas yang muncul ketika pengguna melakukan scroll.
7. Ditambahkan tombol pergantian tema terang dan gelap menggunakan class tema-gelap.
8. JavaScript dibuat terpisah pada js/app.js dan dipanggil menggunakan atribut defer.
